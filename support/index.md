# Learning Tails World Support

Learning Tails World is an offline learning adventure for children ages 3–5.

## Quick help

- **No sound:** Turn up the device volume and make sure Silent Mode is off.
- **Start again:** Open **Grown-ups**, complete the grown-up check, then choose **Delete Local App Data**.
- **Restore the app:** Download it again from the App Store using the same Apple Account.
- **Account help:** Version 1.0 does not require or create an account.

## Device support

Learning Tails World supports iPhone and iPad devices running iOS or iPadOS 17 or later.

## Contact support

Email [learningtailsworld.support@gmail.com](mailto:learningtailsworld.support@gmail.com) for help, general feedback, or feature requests.

When requesting help, include the device model, operating-system version, app version, and a short description of the problem. Do not include a child’s personal information.
